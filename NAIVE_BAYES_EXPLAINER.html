Naive Bayes

A probabilistic classifier built on Bayes' theorem that assumes features are conditionally independent given the class. Fast, interpretable, and surprisingly effective — especially for text classification.

P(class | features) = P(features | class) × P(class) / P(features)

⚠️ The "naive" assumption is that features are conditionally independent given the class. This is almost never true in reality — yet Naive Bayes often works well in practice because we only need the right ranking of class probabilities, not exact values.
✅ When correlation is high, the model double-counts correlated evidence. Despite this, classification accuracy stays surprisingly robust — a phenomenon called the optimistic bias of Naive Bayes.

Prediction
💡 For each class and each feature, Gaussian NB fits a normal distribution N(μ, σ²) to the training data. At prediction time it evaluates the PDF at the query value — the class with higher likelihood wins (assuming equal priors).
