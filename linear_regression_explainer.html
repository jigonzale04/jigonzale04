Linear Regression

A supervised algorithm that models the relationship between a continuous target and one or more predictors — by fitting the line (or hyperplane) that minimises prediction error. Start simple, then go multiple.

// the dataset — 120 fictional houses, 4 features

We have 120 fictional houses described by Size (m²), Bedrooms, Distance to city (km) and Age (years). We want to predict the Sale Price (k€). This is a supervised regression problem — we have labelled examples to learn from.

// simple linear regression — one predictor (size → price)

Start simple: predict Price from Size alone. We fit a straight line. Each dot is a house; the red line is the model's prediction. The grey segments are residuals — the errors.

Price = β₀ + β₁ × Size
β₀ = intercept  |  β₁ = slope (k€ per extra m²)

The slope β₁ means: each extra m² adds that many k€ to the predicted price. The intercept β₀ is the predicted price at 0 m² — mathematically required but not physically meaningful here.
// residuals — what the model gets wrong

A residual is the vertical gap between the actual price and the predicted price. OLS finds the β values that minimise the total squared residuals (SSR).

SSR = Σᵢ ( yᵢ − ŷᵢ )²  →  minimise over β₀, β₁
✅
Residuals should scatter randomly around zero — no pattern. A funnel shape (heteroscedasticity) or a curve (non-linearity) would signal a problem with model assumptions.

// multiple linear regression — four predictors

Now use all four features at once. The model becomes a hyperplane in 5D space — impossible to draw, but the mathematics is identical to the simple case. Each feature gets its own coefficient.

Price = β₀ + β₁×Size + β₂×Bedrooms + β₃×Distance + β₄×Age
β₃ and β₄ expected negative — farther away and older = cheaper
