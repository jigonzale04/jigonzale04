Logistic Regression

A classification algorithm that estimates the probability an input belongs to a class — using the S-shaped sigmoid function to squeeze any number into a 0–1 range.

// why not linear regression?

We want to predict a binary outcome — spam or not spam, tumor or not tumor, fraud or not fraud. Linear regression predicts continuous values and can output nonsense like −0.3 or 1.7 as a "probability". We need something bounded between 0 and 1.

not spam (0) spam (1) linear fit (broken)
⚠️
Linear regression predicts values outside [0,1] — meaningless as probabilities. We need a function that always outputs between 0 and 1, no matter the inputs.
// the sigmoid function — squashing everything to [0,1]
σ(z) = 1 / (1 + e−z)   where   z = β₀ + β₁x
sigmoid curve σ(z)threshold = 0.5
📐
As z → +∞, σ(z) → 1. As z → −∞, σ(z) → 0. At z = 0, σ(z) = exactly 0.5. Always between 0 and 1 — perfect for probabilities.

// decision boundary — where the model draws the line

When σ(z) ≥ 0.5, we predict class 1. This happens when z ≥ 0, i.e. when β₀ + β₁x ≥ 0. That boundary is a line (in 2D: a hyperplane) separating the two classes.

β₀ shifts the boundary left/right. β₁ controls the steepness of the sigmoid — larger β₁ makes the model more confident.
// how does the model learn? — log loss & gradient descent

Logistic regression learns by minimizing the log loss (binary cross-entropy). For each sample, if the true label is y and the model output is ŷ:

Loss = −[y · log(ŷ) + (1 − y) · log(1 − ŷ)]
loss when y=1loss when y=0
🎯
When y=1 and ŷ→0 (wrong answer), loss → ∞. When y=1 and ŷ→1 (right answer), loss → 0. This heavily penalizes confident wrong predictions.

// key concepts — click to explore
Log-odds (logit)
Logistic regression models the log-odds as a linear function of inputs:log(p / (1−p)) = β₀ + β₁x₁ + β₂x₂ + …The logit ranges from −∞ to +∞ — perfect for a linear model. Applying sigmoid gives us back the probability. This is why logistic regression is linear in log-odds space even though it produces a nonlinear probability curve.
