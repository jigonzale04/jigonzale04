Random Forest

Random Forest is an ensemble of decision trees built on bagging + random feature selection. This explainer covers the two families of ensemble learning — bagging and boosting — then dives deep into how Random Forest works, using the same loan approval dataset as the CART explainer.

💡 Bagging (Bootstrap AGGregatING) trains independent models on random data subsets and averages them — attacking variance. Boosting trains models sequentially, each correcting the previous one's errors — attacking bias. Random Forest is a specialised bagging method.
🎯 Total error = Bias² + Variance + Irreducible noise. A single deep tree has low bias but high variance. Bagging averages out the variance. Boosting shrinks the bias by iteratively fitting residuals.

✅ OOB error is a free, unbiased validation estimate — no separate val set needed. It converges as trees are added. Once the OOB curve flattens, adding more trees gives diminishing returns. A typical sweet spot is 100–300 trees.
💡 Key hyperparameters: n_estimators (more = lower variance, slower), max_features (√d for classification, d/3 for regression), max_depth / min_samples_leaf (controls individual tree complexity).

🎯 RF importance averages Gini reduction across all trees — this is far more stable than a single tree's importance. The standard deviation across trees (error bars) tells you how reliable each feature's ranking is.
⚠️ MDI (Mean Decrease in Impurity) importance is biased toward high-cardinality features. For fairer estimates use permutation importance: shuffle each feature's values and measure the drop in OOB accuracy.

💡 The tradeoff: you cannot minimise both simultaneously with a fixed dataset. Simpler models → high bias, low variance (consistent but wrong). Complex models → low bias, high variance (right on average but inconsistent). The goal is to find the sweet spot — or use ensemble methods that escape the tradeoff.
✅ How Random Forest escapes the tradeoff: each tree has low bias (deep, unconstrained). Averaging B decorrelated trees drives variance toward ρσ² (the irreducible correlation floor) — achieving low bias and low variance simultaneously.
